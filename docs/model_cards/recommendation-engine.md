# Recommendation Engine Model Card

## Intended use
Healthcare navigation and provider discovery for educational software demonstrations.

## Out of scope
Diagnosis, prescribing, emergency triage certification, and clinical effectiveness.

## Method
Curated text phrase mapping and a deterministic weighted provider ranking formula.

## Training data
No clinical training data is used. Demo and synthetic provider records are used only for software demonstration.

## Limitations
Small curated vocabulary, incomplete location matching, and no real provider validation.

## Risks
Incorrect specialty or provider navigation may delay appropriate care. This risk is mitigated with emergency overrides and prominent disclaimers.
